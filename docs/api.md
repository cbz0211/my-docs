# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 查询单篇文档

- 请求方法：GET
- 请求路径：/api/docs/{id}
- 功能：按编号返回单篇文档的标题与所在页面。

### 返回示例

```json
{
  "id": 1,
  "title": "使用指南",
  "page": "guide.md"
}
```

> 说明：这里用两个示例接口练习 REST 风格的描述方式。本站是纯静态站点，没有后端服务，请求不会真正发出。
